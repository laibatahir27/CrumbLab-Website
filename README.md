# 🎂 CrumbLab  Bakery Website

CrumbLab is a modern, fully responsive front-end website designed for a premium, specialized bakery. The platform delivers a visually delicious experience showcasing a signature menu focused entirely on gourmet **Cakes, artisanal Donuts, and custom Cupcakes**.

---
## ✨ Key Features

- **Specialized Menu Display:** Dedicated, beautifully styled visual sections showcasing Cakes, freshly glazed Donuts, and decorated Cupcakes.
- **Fully Responsive Architecture:** Flawless user interface across mobile screens, tablets, and desktops.
- **Sweet & Modern UI:** A warm, inviting color palette paired with elegant typography curated specifically to elevate a dessert brand's digital identity.
- **Smooth Navigation:** Interactive, dynamic menu overlay and quick-scrolling anchor points for seamless user exploration.
- **Order Inquiries:** An intuitive contact/order structure built to turn sweet cravings into custom orders.

---

## 🎨 Our Menu Focus

* **Custom Cakes:** From celebration masterpieces to decadent everyday slices.
* **Donuts:** Hand-dipped, uniquely glazed, and perfectly fried confections.
* **Deluxe Cupcakes:** Perfectly portioned treats topped with signature swirl frostings.
